# Sorrel Soap Works

Artisanal cold-process soap prototype showcase and order platform. Small-batch soap made slowly with cold-pressed plant oils, unrefined shea butter, French mineral clays, and cured for 42 days. Palm-oil free, plastic-free, and chemical detergent free.
